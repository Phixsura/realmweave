# Trinity Y v4 —— 三界Y（设计文档）

日期：2026-08-10。方向 A（圣杯搜索）的第一个候选。

## 0. 处刑结论（为什么推倒 v3）

v3 有十条补丁规则（起源禁区、门柱不可剪、化石之路看层数、500 手封顶……），
每条堵一个退化案例。围棋用一条规则（气尽提子）挡住所有退化，因为它
**攻防同一**：包围你就是在建立我。补丁数量 = 核心机制撑不起涌现的证据。

## 1. 理论基石：Y 定理

游戏 Y（Schensted & Titus, 1953）：三角形棋盘，双方共享同一目标——
用一条连通链接触全部三条边。**定理：填满的三角形上恰有一人达成 Y。**
（Hex 定理的推广；证明via Sperner 引理。）

这给了我们数学保证的攻防同一：
- 你阻挡对手 Y 的每一颗子，都自动是你自己 Y 的一部分——**挡即是建**；
- 没有和棋、没有死局、没有需要补丁的退化案例；
- 我们的随机填盘审计：单三角 NOBODY 达成率 **0.00%**（对照：v3 的
  hex 板点目标下 53% 的随机填盘无人获胜——这就是死棋的来源）。

## 2. 全部规则（真的只有三条）

1. 轮流在任意空点落一子（后手第一手可换边——pie rule）。
2. 一个界域被"织成"：某方的一条连通链接触该三角形的全部三条边。
   Y 定理保证每个界域终将恰好属于一人。
3. **先织成两个界域者赢下对局。**

没有起源、没有剪刀、没有禁区、没有封顶。资源只有**手数本身**：
在一个界域落子，就是在另外两个界域让先。

## 3. 三界的意义（不是三盘平行的 Y）

天平结构：三个界域共享同一个回合时钟。第二界域打成 1:1 后，第三界域
成为决战场——但任何一方都可以中途"换战场"，在对手重兵界域让先、
在空虚界域抢先。战略层 = 手数在三个战场间的分配，这是单盘 Y 没有的
维度，也是 Realmweave"三界"身份的规则化表达。

实测（bot 自对弈，边长 16 ≈ 136 格/界，408 格总盘）：
- 手数 185~345（边长可调节：11→87，16→300+，19→400+）
- 界域事件铺满全局：如 (31,[1,0]) → (178,[1,1]) → (311,[2,1])
  ——先手拿下第一界，后手扳回第二界，第三界 130 手决战。

## 4. 与 issue #1 的关系

- 三界拓扑：保留（三个三角形界域）
- Weave（连接目标）：保留且升格为唯一规则
- 门/起源：v4.0 取消（门是 v1 点目标模型的产物）。若人测发现界域间
  互动不足，v4.1 的第一个实验是把三个三角形沿边缝成一个闭合曲面
  （四面体的三个面），跨界连接成为规则的自然延伸——依然零补丁。
- "not a 3D Go clone"：Y 家族与围棋机制（气/提子/目）无交集。

## 5. 已知风险（诚实清单）

- **单界 Y 有先手优势**，pie rule 是标准解（Y 社区共识）；三界结构下
  先手优势的形态未知，需要真人对局数据。
- bot 目前的界域切换时机策略很浅（2-ply），三界让先博弈的真实深度
  要等更强的搜索或真人来验证。
- 边长 16 的 300 手里有多少是"每一手都有意义"？需要真人手感裁决——
  不再用代理指标自欺。
