# Supply War — 详细设计 v2（定稿候选）

状态：**待用户确认后实现**。取代 design-supply-war.md（v1 及其补丁保留
作为演变记录）。v2 = v1 + 两轮调研的全部校准**融贯重写**，并用纸面

## 0. 设计宪法（来自两轮调研，凌驾于一切具体条款）

1. **守连接，不守建筑**——独占定位；敌人剪线，不打节点；
2. **波峰紧张 + 间歇禅意**——压力有呼吸，铺线本身是放松的；
3. **推回必有代价**——收复是远征，不是碾压（反 CW "慢推 grind" 差评）；
4. **随机只在开局**——种子决定一切，中途零暗骰（反 MiniMoto RNG 差评）；
5. **失败快、可读、秒重开**——死因回放 + 一键再来（反 TAB 长局差评）；
6. **有终局**——关卡制战役；无尽模式是后置选项；
7. **多人 = 远期 co-op，永不 PvP**（Tooth&Tail 65% Mixed 墓碑）。

任何后续改动若与宪法冲突，改动无效。

## 1. 架构

### 1.1 确定性 tick 模拟
- 逻辑步长 `TICK = 100ms`（10/s），渲染与逻辑解耦（Bevy `FixedUpdate`）。
- 全部随机来自 `seed: u64`（地图生成 + 敌人出生点选择）。
- 玩家输入 = 指令流 `Vec<(tick, Command)>`。
- **回放 = seed + 指令流**；死因回放、每日挑战、测试全部由此免费获得。

```rust
// realmweave-supplywar crate，零 Bevy 依赖
pub struct SimState { /* 图、能量、线路、敌人、波次、结果 */ }
pub fn tick(state: &mut SimState, commands: &[Command]);   // 每 tick 一次
pub enum Command { BuildLink(EdgeId), Reinforce(EdgeId), Pulse(NodeId) }
```

### 1.2 世界即图
复用 `BoardDefinition` 数据结构（单层 = hex 生成器 Mortal 层 + 挖洞）。
连通性/距离全部走图；渲染坐标只管画。`EdgeId = u32`（edges 数组索引），
与 weave-sever-v2 的约定一致。

| 要素 | 规格 |
|---|---|
| 基底 | hex 半径 4 单层（61 节点）|
| 挖洞 | 种子移除 8~12 个节点；约束：剩余图连通、母核到全部资源点可达、到全部出生口可达 |

## 3. 经济

单资源**能量**。v1 数值经纸面模拟发现开局过松（波 1 前即顶上限、
满脉冲预算），v2 收紧：

| 项 | v2 值 | v1 值 | 调整依据 |
|---|---|---|---|
| 开局能量 | **30** | 40 | 开局只够铺 3 线，第一口井是真决策 |
| 母核产出 | +1.0/s | 同 | |
| 每口井产出 | **+1.2/s** | 1.5 | 全接通收入 7/s，压在脉冲费率之下 |
| 能量上限 | **80** | 100 | 波前满仓 ≈ 5 次脉冲，防囤积更狠 |
| BuildLink | **10** | 8 | 配合 E0=30：开局 3 线 |
| Reinforce | 12 | 同 | |
| Pulse | 15 | 同 | |

**验证过的节奏**（纸面模拟）：开局 30 + 核产 → 接通第 1 口井 ~t=15s、
第 2 口 ~t=35s → 波 1（60s）到来时能量 ~60、收入 3.4/s——**够 3 次脉冲
或 1 次脉冲+1 次加固，不够两者兼得**。间歇期（90s）收入 ~300 但上限 80
逼迫持续投资（扩井/加固/收复远征）。第 3 波满配 8 敌，满仓 80 = 5 脉冲，
必须依赖加固与布局，不能纯脉冲清屏。

## 4. 网络规则

### 4.1 铺线 BuildLink(edge)
- 合法：两端至少一端**点亮**；未建造或**已被切断**（切断的边可全价
  重建——虚空不能永久占有地图）；能量 ≥10。
- 扣费即刻；**建造 1.5s**（15 tick）；建成瞬间做连通性刷新。
- 建造中可被切（中断，退 50%）。
- **点亮 Lit** ≝ 节点经已建成线路连通母核。

### 4.2 加固 Reinforce(edge)
- 合法：已建成、未加固、能量 ≥12。
- 双线：被切一次降回单线（线不断、网不熄）。不可叠加。

### 4.3 断线 → 熄灭 → 重接（核心戏剧）
- 切断即重算连通分量（增量 BFS）。
- 断连子网**熄灭**：停产、0.5s 渐暗；线路成**残骸**留图。
- **残骸不可扩建**（点亮判定严格走 4.1）——必须先接回。
- 重接：接点波浪式重亮（0.3s 扩散动画，第一视觉奖励）；
  残骸复用免费 → 抢修是高价值动作。

### 4.4 脉冲 Pulse(node)
- 合法：node 点亮、能量 ≥15、全局冷却 3s 已过。
- 效果：图距 ≤2 的所有切割者：中断读秒、向其出生口方向弹退 3 格、
  眩晕 2s。**不击杀**（压力守恒；"清除"的满足感由收复机制承担，
  见 §5——这是对调研校准#1 的分工式回应：脉冲管急、收复管本）。

### 4.5 收复 Reclaim（慢性胜利线，宪法 #3 约束下的设计）
- 把线路铺至出生口节点并点亮 → 该出生口**封闭**（本波及以后不再出敌）。
- **远征代价**（三重，防 CW 式无脑碾压）：
  1. 出生口距母核 ≥6 → 收复线 ≥6 段 ≈ 60+ 能量的项目；
  2. 收复线天然横穿敌人来袭走廊——是全场最易被切的线；
  3. 封口状态依赖收复线**保持点亮**：护线熄灭 → 出生口立即重开。
- 全部 3 口封闭 = **提前完胜**（第四胜利路线，奖励进攻型玩家）。

## 5. 切割者

行为 = 每 tick 评估的状态机。无全局智能；威胁 = 行为规则 × 数量 × 方向。

**饱食退场 + 任期**（实现修订，D2 诊断发现）：切割者成功切割 **2 次**
后退场；无论吃没吃饱，**出场 90 秒后强制退场**。两条缺一不可：没有
饱食则波次永久累积；没有任期则"全程脉冲"策略会让敌人饿着不走、
越攒越多（打断切割 = 敌人吃不饱 = 永不退场——一个真实的涌现陷阱，
现在变成了有趣的取舍：脉冲救急但留人，喂线退敌但断网）。

### 5.1 爬行者 Crawler
| 属性 | 值 |
|---|---|
| 索敌 | 图距最近的已建成线路（含收复线、残骸不算）|
| 移速 | 0.8s/格 |
| 切割读秒 | 3s（头顶进度环）|
| 被脉冲 | 中断+弹退 3 格+眩晕 2s |

### 5.2 潜行者 Stalker
| 属性 | 值 |
|---|---|
| 索敌 | 仅"单线且断开将致 ≥2 节点熄灭"的边（真动脉）；无目标即原地休眠（可见，教学信号）|
| 移速 | 0.5s/格 |
| 读秒 | 2s |
| 首次出场 | **先教后罚**（宪法#2）：全局慢动作 2s + 高亮其锁定边 + 一行提示 |

### 5.3 波次（切片 3 波，全部开局公示）
| 波 | 时刻 | 构成 | 进场口 | 教学点 |
|---|---|---|---|---|
| 1 | 60s | 爬行者×3（间隔 5s）| 单口 | 脉冲 |
| 2 | 150s | 爬×4 + 潜×1 | 单口 | 加固动脉 |
| 3 | 240s | 爬×5 + 潜×3 | **双口同时** | 防线取舍 / 收复的回报（封掉一口=第 3 波减半）|

- 波前 10s：屏缘方向箭头 + 构成图标（信息全透明）。
- **终场哨**（实现修订）：最后一个计划刷怪时刻 + 60 秒 = 固定结算点。
  守到哨响且 ≥3 井点亮即胜——波 3 幸存者的持续压迫是设计内的
  终盘戏剧，而非无限消耗战（首版"敌人全部游荡"判定会造成
  修线-切线死循环，已废弃）。

## 6. 胜负与"失败体验"（宪法 #5 的完整落地）

- **胜**：撑过第 3 波，母核在亮，≥3 口井点亮；或提前封闭全部出生口。
- **负**："网络死寂"= 母核全部邻接线被切 && 能量 <10。
- **判负瞬间**：
  1. 屏幕定格 → 自动回放**最后 30 秒**（确定性引擎直接快退重放），
     断线事件红色高亮 + 时间轴标注（"t=214s 动脉 A-B 被切，7 节点熄灭"）；
  2. 结算屏两个大按钮：**同种子再来** / **新种子**（一键，零加载——
     SimState 重建 <10ms）。
- 星级：★通关 ★★全 5 井终局点亮 ★★★熄灭事件 ≤2 或 提前完胜。
- 存档：切片不做（一局 6 分钟）；v1 做（15-25 分钟关卡时为硬需求）。

| # | 情形 | 裁定 |
|---|---|---|
| 1 | 铺线两端都未点亮 | 非法 |
| 2 | 建造中被切 | 中断、退 50%、切割者重索敌 |
| 3 | 双线被切两次 | 一次降单线、二次断 |

## 8. 呈现（灰盒规格，一屏读懂）

- 俯视 3D，45° 锁定俯角。**形状=语义**（沿用棋客户端教训）：
  母核=大金球脉动；井=绿晶体；普通节点=小灰点；残骸=暗红烬；
  出生口=紫色裂隙（封闭后=金色封印）。
- 线路：能量流光从母核方向流出（**流向即读图**）；建造中=进度生长；
  双线=平行双轨；残骸=暗红虚线。
- 切割者：红锥（爬）/紫刃（潜，休眠时半透明）；读秒=径向进度环。
- 交互（无模式切换）：点空边=铺线；点已建线=加固；右键节点=脉冲。
  悬停任何东西显示 tooltip（成本/产出/威胁）。
- HUD：左上能量条+收入率；顶部波次时间轴（全局可见的 3 波刻度）；
  右下目标清单；判负=死因回放屏。
- 音效/美术：无（灰盒验手感）。
