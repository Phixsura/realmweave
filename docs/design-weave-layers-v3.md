# Weave Layers v3 —— 层层编织（设计文档）

日期：2026-08-10。前置：docs/design-weave-sever-v2.md（v2 的全部机制在 v3 内保留，除非本文覆盖）。

## 0. 为什么要 v3

v2 的结构性天花板：胜利条件是"一次性连接三个起源"，连接本身只需要 25~35 颗子，
所以无论棋盘多大、bot 多强，对局都在 30~50 手内结束。诊断结论：

> 一次性连接目标给不了 300 手；瓜分盘面目标就是围棋（issue #1 明令禁止）。
> 出路是把胜利条件改成**多次、递进、消耗盘面**的目标。

v3 的核心句：**编织不再结束游戏——它改变世界，然后游戏在被改变的世界里继续。**

## 1. 规则总述（相对 v2 的差异）

1. 完成编织（连通三个起源 + 挺过对手一回合确认，与 v2 相同）得 **1 层**，
   不结束游戏。
2. 确认瞬间，编织者连接三个起源的**整张网固化**（petrify）：
   - 网内所有本方棋子变为**中立的世界结构**——不属于任何一方、不可落子、
     不可通行（等同石壁）、其相邻边不可剪（固化的世界不可再改）。
   - 例外：**与任一起源相邻的棋子不固化，直接移除**（返回空点）。
     起源必须永远保有呼吸口，否则自己的胜利会把自己闷死。
3. 固化后双方剪刀各 **+2**（上限 4）。剪痕跨层保留——世界的伤疤不愈合。
4. 先积满 **3 层**者胜（`layers_to_win` 可配置）。
5. 绞杀胜保留：任一方三个起源永久无法互连，对方立即获胜（不看层数）。
   起源禁区（sanctum）与起源边保护同 v2。
6. 连续两次 Pass：层数多者胜；同层数为平局。盘面满同理。

## 2. 为什么这些选择

**固化 = 康威式规则自迭代。** 每一层的最优路线被固化成障碍，第 N+1 层
被迫寻找全新拓扑。世界按对局自身的历史变形——"每局都是新棋局"在一局
之内也成立。

**得分者付出全部盘面资产。** 你的网固化 = 你的活子全部消失，对手的子
全部保留。领先者每得一层就"从零开始 vs 对方的常备军"——天然的
rubber-band，比分越接近终点，追赶方越有结构优势。竞速不再是单调冲刺。

**起源呼吸口（origin-adjacent 不固化）。** 没有它，第一层的网会把自己
的起源封进石壁，游戏退化为"谁先得分谁先死"。移除（而非固化）这些棋子
同时意味着：起源周围永远是可争夺的活地。

**剪刀按层补给。** v2 的 3 把剪刀在 40 手内刚好；150+ 手的对局里剪刀
必须再生，否则后期退化为纯落子。按层 +2、上限 4：保持稀缺、防止囤积。

**手数量级估算。** 第 1 层 ≈ v2 全局 ≈ 30~50 手；第 2、3 层路线更稀缺
且对手有存军，只会更长。3 层 ≈ **120~250+ 手**，且每 40~60 手一个
高潮（确认回合攻防）——比均匀的 300 手更有戏剧结构。

## 3. 边界情形

| # | 情形 | 裁决 |
|---|------|------|
| 1 | 固化网触及对方棋子 | 不可能：网 = 本方棋子 + 起源的连通分量，异色不连通 |
| 2 | 固化后本方起源被石壁+旧剪痕永久隔断 | 绞杀判定照常跑：**对手立即获胜**。固化自己的最后通路是合法但自杀的下法——设计上允许（深度：得分前要看好下一层的出路） |
| 3 | 固化后**对方**起源被隔断 | 同样照常：编织者同时达成层数+绞杀，绞杀优先，直接全胜 |
| 4 | 双方同回合内都有 pending weave | 不可能：确认需要挺过对手整回合，同一时刻至多一方 pending |
| 5 | 剪刀上限 | 补给后 >4 截断为 4 |
| 6 | 移除的起源邻子被重新落子 | 合法，任何一方都可以（sanctum 只限制敌方起源邻点） |
| 7 | 第 3 层的网固化 | 不固化——达到 layers_to_win 即终局，盘面保留为终局画面 |
| 8 | Pass 连锁 | 两连 Pass 终局：层多者胜、平层为平局 |

## 4. 状态与兼容

`GameState` 新增：
- `petrified: Vec<bool>`（serde default 空 = 全 false，旧记录兼容）
- `layers: [u8; 2]`（default [0,0]）

回放不变式保持：局面 = config + move log 完全重放。

## 5. 验收标准

- bot 自对弈（61×3）：手数中位 ≥ 120，各层胜法混合出现，剪刀在每层被使用
- 第 2 层的路线与第 1 层显著不同（固化逼出新拓扑）
- 追赶方胜率不塌方（rubber-band 生效的间接证据：先得 1 层者最终胜率 < 75%）
- 客户端：固化子有独立视觉（灰色石壁），HUD 显示层数比分，教程/演示可用
