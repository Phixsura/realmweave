## 1. 一句话

**在悬浮于虚空的三层破碎世界里，铺设你的光之网络，剪断敌人的——
被切断补给的一切都会熄灭。**

## 2. 幻想（玩家扮演什么）

你是"织网者"（Weaver）。世界曾是一体，如今碎成三层浮岛：
**天界**（稀薄、高远）、**人间**（破碎的主战场）、**冥界**（幽深、致密）。
你的母核（Origin）苏醒，能量线从它蔓延——每点亮一个节点，
黑暗就退一步。但虚空里有别的东西：**切割者**（Severers），
它们循着你的光而来，专剪你最脆弱的动脉。

视觉基调沿用 issue #1：cosmic / mythic，节点是能量星核，
**readability > spectacle**——但现在"光之网络在黑暗中生长"本身就是
最大的视觉奇观，两者不再冲突。

## 3. 核心循环（30 秒体验）

```
观察 → 我的网络边缘在哪？敌人下一波从哪个方向来？
决策 → 三选一，每 5~10 秒一次：
        ① 延伸：铺一段新线路，点亮下一个节点（扩张=得分/资源）
        ② 加固：把一段单线升级为双线（冗余=保险，贵）
        ③ 反制：对准逼近的切割者释放脉冲（防御，消耗能量）
反馈 → 线路被剪的瞬间：下游整片网络变暗熄灭（心跳时刻）；
        抢修接回：整片重新亮起（如释重负）。
```

紧张感的来源是一个恒等式：**你的网络永远比你的防御长。**
每一段扩张都在增加你要守的边界——贪婪与稳健的实时权衡。

## 4. 三层的意义（这次必须真的有意义）

| 层 | 性质 | 战略角色 |
|---|---|---|
| 天界 | 节点稀疏，线路跨距长 | **高速公路**：连得快、跨得远，但单线脆弱，被剪损失大 |
| 人间 | 标准密度，资源节点所在 | **经济腹地**：主要得分/资源来源，主战场 |
| 冥界 | 节点致密，线路短 | **地下掩体**：铺设慢、成本高，但切割者难以到达 |

**门柱（Gates）**：三层之间唯一的通道，数量稀少（沿用 12 门设计）。
关键线路走哪层、在哪个门换层，是核心策略。高风险高速 vs 高价低速——
三层第一次成为"选择"而不是"负担"。玩家不需要同时阅读三层：
**任一时刻只需要看自己线路经过的那几段**，认知负担被路径化了。

## 5. 对手设计（先 PvE，PvP 后置）

v1 不做人人对战（回避实时对抗平衡的深水区），对手是**切割者潮水**：

- **爬行者**：沿最短路逼近你最近的线路，抵达后开始切割（读秒），
  脉冲可驱散——教学级威胁；
- **潜行者**：只袭击"单线无冗余"的边——直接惩罚贪婪，教你加固；
- **门蛀**：专攻门柱线路——把跨层动脉变成高价值防守点；
- **潮汐节奏**：波次间歇期建设，波峰期防守，仿 Creeper World 的
  呼吸感。波次构成 = 关卡设计语言。

AI 不需要"聪明"，只需要"有指向性"——每种切割者是一条固定行为规则，
组合出压力。这绕开了我们被验证过的 bot 短板（不需要全局博弈 AI）。

## 6. 一局的结构（15~25 分钟一关）

1. **落点**（1 分钟）：看地图，选母核初始朝向；
2. **铺网**（前 1/3）：抢在第一波前接通最近的资源节点；
3. **拉锯**（中段）：扩张↔防御的节奏交替，第一次大断线通常发生在这里；
4. **决胜**（后 1/3）：达成关卡目标——点亮全部起源柱 / 存活 N 波 /
   接通对角远点；
5. 结算：点亮率、最长存活链、被剪次数 → 星级。

## 7. 与既有资产的关系

| 资产 | 去向 |
|---|---|
| 图引擎/连通性/BFS | **核心复用**——断线检测=连通分量计算，全是现成的 |
| 板生成器（三层 hex + 门） | 复用为地图骨架，叠加"破碎化"（挖洞）做关卡变化 |
| 确定性状态机 | 保留！实时=固定 tick（如 100ms）驱动的确定性模拟，回放/测试照旧 |
| RuleSet 六套棋规则 | 冻结存档（不删除），棋模式降级为隐藏彩蛋 |
| 服务器/协议 | v1 不用（单机），架构保留给未来 PvP |
| Bevy 客户端 | 相机/三层渲染/拾取复用，UI 重做 |
| annotate/回放 | 变成"战报回放"功能 |

## 8. 垂直切片定义（验收目标，非 v1 全量）

**一张人间单层小地图（先不上三层）+ 母核 + 2 种切割者 + 3 波潮水：**

- 能铺线（点击相邻节点延伸）、能加固（双线）、能放脉冲；
- 切割者按规则逼近、读秒切割、被脉冲驱散；
- 断线时下游熄灭（连通分量实时计算 + 变暗动画）；
- 接回时重新点亮；
- 目标：存活 3 波并点亮 5 个资源节点。

**验收问题（唯一标准）**："看着网络生长与被剪"这个核心体验，
能否让你玩完 10 分钟后想再来一局？由你亲手玩来回答。

切片刻意不含：三层、门柱、天赋/科技、剧情、音效、PvP。
核心画面不成立的话这些都没有意义。

## 9. 风险与止损线

- **最大风险**：实时手感（拖拽铺线的顺滑度、切割的威胁可读性）不是
  图论问题，是游戏手感问题，我们第一次做。缓解：切片只做一层+两种敌人，
  失败成本 3 天；
- **止损线**：切片验收不通过且无明确可修点 → 回到方向 B（解谜），
  引擎积累全部沿用；
- **范围纪律**：任何"不如加个塔防炮台/英雄单位"的冲动都先记入
  backlog 不实现——差异化核心是"网络本身是唯一的单位"。
