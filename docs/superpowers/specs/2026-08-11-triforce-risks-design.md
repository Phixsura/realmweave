# 织心 v5 两风险点解决设计（2026-08-11）

用户裁决：测量+手术都做完，用开关切换；换边用双搜索比较胜率；
五边形化取"心区抓稀：删点+重三角化"。

## 1. 中心优势测量工具（realmweave-sim `center` 子命令）

`realmweave-sim center --board tf22-v5 --games N --playouts P [--seed S]`

- 开局分层自对弈：强制第一手落 心区中央 / 角区腹地 / 大边中点，
  其余交 MCTS，各 N 局 → 三组先手胜率。
- 自由对局热力：前 20 手心区占比、获胜链心区节点占比。
- 判据（固化于报告与本文档）：
  - 心开局先手胜率 − 角开局先手胜率 ≥ 15pp，或
  - 自由对局前 10 手心区占比 ≥ 60%（心区面积占比 ~22%）
  → 判"中心过强成立"。
- 纯读，复用 MCTS 与 `triforce_region`，零规则改动。

## 2. 五边形化变体 tf{side}-v5p（心区抓稀）

- `boardgen::generate_triforce_pierced(side)`：织心内部按 120° 旋转
  对称模式删 ~1/4 内部节点（不动心区边界，角-心接缝不变），空腔
  周边重新三角化。
- 不变量测试：镜像自同构、全图连通、无孤立点、内部面全三角
  （Y 定理前提）、删点模式旋转对称。
- `resolve()` 识别 `tf22-v5p`；client 渲染零改动（family 不变）。
- `triforce_sides` / `triforce_region` 在删点重映射下必须仍正确 —
  改为对 v5p 用查表（定义文件内数据），不用公式。
- 菜单提供 v5p 棋盘选项（与 v5 并存切换）。
- 测量工具对 v5 / v5p 各跑一遍 → 并排数据 = 真人裁决材料。

## 3. MCTS pie-rule 换边（双搜索比较胜率）

- `mcts` 暴露根胜率：新 API 返回 `(Move, f64)`。
- `choose_move_with_budget`：当 `validate(Swap).is_ok()` 时——
  - 搜索 A：本方正常搜索 → 最佳落子 + 胜率 p_move；
  - 搜索 B：换边后局面（首子归我、对方行棋）估值 → p_swap；
  - `p_swap > p_move + 0.02` → 返回 `Move::Swap`。
  仅此一手预算加倍，可接受。
- 回归测试：心点开局 → Strong 应换边；角落最劣点开局 → 不换。

## 交付顺序

1. 测量工具 → 跑 v5 基线；
2. v5p 生成器 + 不变量测试 → 跑 v5p 对比；
3. MCTS 换边（独立）；
4. 文档记录判据与两组数据。每步全 gauntlet。

产出：两张棋盘、中心优势对比报告、会换边的 AI。
最终"用哪张板"仍由真人手感裁决——本工作只备齐裁决材料与开关。
