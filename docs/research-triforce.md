# 深度调研：Triforce 几何（合并三角 + 死亡规则）

日期：2026-08-10。触发：用户真人对局反馈四症状——开局无方向、每手无张力、
AI 不可读、三界像三盘孤立的棋。诊断：三界只共享回合时钟=没有真实耦合。

## 一、外部研究结论（来源见文末）

### Y 棋六十年的核心教训：平面三角的中心太强
- Y 的头号公认缺陷：平面三角板上**控制中心者可轻松到达任意边**
  （中心到边距离仅为边长 1/3），守边近乎不可能。
- Schensted 的官方"弯曲板"（三个五边形点、测地穹顶压平）就是为此发明：
  把中心/边比从 1/3 改善到 3/4，**削弱中心、增强边角**。
- 先手优势严重：策略偷取证明先手必胜；pie rule 是最低标配；顶级玩家
  David Bush 认为测地板连 pie rule 都不够，建议三手均衡制。
- 尺寸数据：商业弯曲板 93 点被评"太小，先手基本必胜"；社区经验
  边长 13+ 战略才压过战术；多目标记分类的成熟答案是 **170–210 格**
  （Side Stitch 169、Poly-Y 208）。

### Go+连接混血的统一教训：必须有防死锁阀
- Gonnect（Neto 2000，围棋全规则+连边胜）：初版被双眼死锁卡死，
  解法是**禁止 Pass**；高手局退化为领地博弈（"四角僵局"后填气定胜负）。
- Slither/Crossway/Resolve 各自用不同的阀（禁斜切/移子/自动清算）。
- 我们的 v4.1 天然有阀：Y 定理保证有人必胜，无双眼死锁问题——
  但 Gonnect 的教训提醒：高手会把它玩成领地棋，需真人验证。

### 多目标连接棋：方向感来自"目标的多元与竞争"
- Poly-Y（Schensted）：奇数条边、Y 夺角、多数角胜——明确记载其胜利条件
  "推动玩家把棋组延伸到全盘、穿过中心互相封锁"——**多目标结构本身
  制造方向感**。角数是深度旋钮：太多则短边被廉价夺角、退化为局部战术；
  9 角×7 格/边是他试出的最优。
- Side Stitch（2017）：hexhex 板边框分成 N 段彩色边、最佳棋组触边数
  计分——最接近"给边框区域赋予身份"的现有设计，以可读性和全盘感著称。
- **没有找到任何把棋盘内部划分为身份区域的连接棋**——三界嵌入大三角
  属于未被探索的设计空间（边框身份有先例，内部身份没有）。

## 二、本地实证（examples/triforce_*.rs）

边长 22 合并三角（253 格；三角界域各 66 格 + 织心 55 格）：

| 指标 | 结果 | 解读 |
|---|---|---|
| 随机填盘决定性 | **100.00%**（3000 次，0 死局） | Y 定理在合并板上完整成立 |
| 胜利棋组跨 ≥2 界域 | **100%** | 耦合不再是抽象时钟——胜利之路必然穿越多界 |
| 胜利棋组经过织心 | **100%** | 中心是所有战略的交汇处 |
| 界域相互直接邻接 | 是（六对全邻接） | 织心不是强制隘口，是价值高地——可绕但不划算 |
| 死亡规则下随机自对弈 | 中位 242 手、场均 18 提子、0 未决 | 长度域正确，提子活跃 |
| 开局价值梯度 | 织心 18.5% > 界域 ~16% | 梯度存在但温和（随机 playout 会低估；研究警告真实差距更大） |

## 三、综合判断

1. **方向 confirmed**：合并三角直接解决四症状，且"内部身份区域"在设计空间
   里是空白——差异化成立。
2. **最大风险 identified**：Y 的中心过强问题。我们有两张牌研究界没有：
   - **死亡规则**：中心大链可以被围杀——占中心必须活形，这本身就是
     制衡（Gonnect 证明活形代价真实存在）；
   - **织心可以做几何手术**：如果实测中心仍过强，按 Schensted 弯曲板
     思路在织心引入低连接度点（五边形化）——正好贴合"织心是异界"
     的叙事。
3. **尺寸定标**：边长 22（253 格）落在 170-210 经验带之上、与死亡规则的
   242 手自对弈匹配；备选边长 20（210 格）。
4. **平衡预案**：pie rule 保留；若不足，Bush 的三手均衡制是成熟备选。
